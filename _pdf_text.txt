Б хэсэг — Postman Collection бичих (Анги дотор + Гэрт) 
Сонгосон API-аасаа дор хаяж 8 request-ийг зохион байгуулна. Тестээс өмнө collection-ыг 
"document" мэт ашиглахуйцаар цэгцлэх нь чухал. 
Шаардлагатай request-ийн төрөл (бүгд байх ёстой) 
Доорх 6 төрөл бүрээс ≥ 1 request байх ёстой. Нийт ≥ 8 request. 

Төрөл 
Юу шалгана 
Жишээ 
Happy GET 
200, body байгаа 
GET /users (list) 
GET by id 
200 эсвэл 404 
GET /users/1 
POST create 
201, шинэ id буцаах 
POST /users 
PUT/PATCH 
200, өөрчлөлт хадгалагдсан 
PUT /users/1 
DELETE 
204 эсвэл 200 
DELETE /users/1 
Error case 
4xx (400/401/404) 
GET /users/999999 
Зохион байгуулалтын шаардлага 
• 
Folder ашиглан request-уудыг бүлэглэх (жишээ нь: "Users", "Auth", "Errors") 
• 
Бүх URL `{{baseUrl}}` хувьсагчтай — hardcode хийсэн URL fail-д хүргэнэ 
• 
Auth шаардсан endpoint-д Authorization header-ийг collection-level дээр тохируулах 
(request-бүрд давтахгүй) 
• 
Body нь JSON-той бол `application/json` content-type автомат тохируулагдсан байх 
• 
Бүх request-д товч description (1 мөр) бичсэн байх 
Жишээ: chained request 
Нэг request-ийн response-оос дараагийнх нь хэрэглэх хувьсагч авах нь Postman-ы зүрхэн 
боломж. Login → Token → Get profile-ийн жишээ: 
// Login request → Tests tab  
const json = pm.response.json();  
pm.environment.set("token", json.token);  
pm.environment.set("userId", json.id);   
// Get profile request → Authorization  
// Header: Authorization: Bearer {{token}}  
// URL:    {{baseUrl}}/users/{{userId}} 
В хэсэг — Test script бичих (Гэрт) 
Postman-ы хамгийн чухал хэсэг — Tests tab-д JS код бичин баталгаажуулалт нэмэх. 
Pass/Fail тоо нь Newman report-д харагдана. 
Шаардлагатай assertion-ы төрөл (≥ 5 төрөл, нийт ≥ 15 тест) 
Assertion төрөл 
Жишээ 
Status code 
pm.response.to.have.status(200) 
Response time 
pm.expect(pm.response.responseTime).to.be.below(1000) 
JSON schema / property 
pm.expect(d).to.have.property("email") 
Утгын тип 
pm.expect(d.id).to.be.a("number") 
Бизнес дүрэм 
pm.expect(d.email).to.match(/@/) 
Header 
pm.response.to.have.header("Content-Type") 

Жишээ: бүрэн test script 
pm.test("Status 200", () => {    
pm.response.to.have.status(200);  
});   
pm.test("Response < 1s", () => {    
pm.expect(pm.response.responseTime).to.be.below(1000);  
});   
pm.test("Schema valid", () => {    
const d = pm.response.json();    
pm.expect(d).to.have.property("id");    
pm.expect(d).to.have.property("email");    
pm.expect(d.email).to.be.a("string").and.match(/@/);  
});   
pm.test("Content-Type = JSON", () => {    
pm.expect(pm.response.headers.get("Content-
Type")).to.include("application/json"); 
});

Newman local-д ажиллуулах 
•

•

•

•

GitHub Actions workflow 
Repo-д .github/workflows/api-tests.yml файл үүсгэн дор хаяж push дээр Newman ажиллах CI 
бүтээх: 
# Workflow-ийн нэр 
name: API tests 
 
# Хэзээ ажиллах нөхцөл 
on: [push, pull_request] 
 
jobs: 
  newman: 
    # Ажиллах орчин 
    runs-on: ubuntu-latest 
     
    steps: 
      # 1. Кодыг татаж авах 
      - name: Checkout repository 
        uses: actions/checkout@v4 
 
      # 2. Node.js суулгах 
      - name: Install Node.js 
        uses: actions/setup-node@v4 
        with: 
          node-version: 20 
 
      # 3. Newman болон нэмэлт хэрэгслүүдийг суулгах 
      - name: Install Newman 
        run: npm install -g newman newman-reporter-htmlextra 
 
      # 4. Newman тестүүдийг ажиллуулах 
      - name: Run API tests 
        run: | 
          newman run postman/collection.json \ 
            -e postman/env.ci.json \ 
            --reporters cli,junit,htmlextra \ 
            --reporter-junit-export reports/api.xml \ 
            --reporter-htmlextra-export reports/api.html 
 
      # 5. Тестийн тайланг файл хэлбэрээр хадгалах 
      - name: Upload Artifact 
        uses: actions/upload-artifact@v4 
        if: always() # Тест амжилтгүй болсон ч тайланг татаж авах боломжтой байлгах 
        with: 
          name: api-test-report 
          path: reports/ 
• 
Workflow-ийн ≥ 1 run амжилттай ногоон болсон байх (Actions tab-д харагдана) 
• 
Secret token хэрэгтэй бол GitHub Secrets ашиглан env.ci.json-д placeholder substitute 
хийх
